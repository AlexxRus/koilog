**Честные пределы EMG (обязательно указать):**
- sEMG ≠ физическая сила: кросс-ток, амплитудная отмена, глубина мышцы, расположение электродов влияют на %MVC (Vigotsky et al., 2017);

## §7 Честные пределы

- **Доли — сравнительная метрика, не биомеханическая истина:** sEMG (%MVC) зависит от техники, нагрузки, протокола; интерпретация «мышца X работает сильнее» = недопустимый вывод.
- **Конфликт протоколов неизбежен:** разные исследования используют разные условия (100% 1RM vs собственный вес, мужчины vs женщины, фаза движения). Медиана ≠ абсолютная истина.
- **«Не измерено ≠ ноль»:** профили без данных помечаются fallback с явной меткой «не измерено»; никогда 0.
- **Экстраполяция (C-уровень):** при отсутствии данных используется эвристика (например, «экстраполяция с жима лёжа») — помечается в провенансе.
- **Вывод:** модель display-only; ранги с envelope ±20%; без порогов/стрелок в рендере.
