## 1. Ожидание (что обещано)

Единственное место в README, где сформулировано поведение без выгрузки, — строки 372–374:

> «Если файла выгрузки рядом нет (чистый клон), шаг не падает: стадия помечается
> "нет файла — работаю от базы", а `load_daily`/эпизоды пересобираются из того, что уже
> лежит в таблицах.»

Разложение обещания на проверяемые части:

1. отсутствие файла выгрузки не валит шаг;
2. стадия помечается текстом (видно, что произошло);
3. `load_daily` и эпизоды **пересобираются из таблиц**.

Пункт 3 — неявная посылка: обещание предполагает, что таблицы часов (`aw_daily`,
`aw_workouts`) уже есть. Настоящий чистый клон (нет `data/`, нет `sql/`) этому условию не
удовлетворяет по построению. Отсюда и весь конфликт: README обещает поведение для
«чистого клона», а реализация его гарантирует только для «базы без свежего файла».

### 2.4. Сводка дефектов

- **D1. Ложное утверждение вместо отказа.** `digest` на пустой базе отдаёт код 0 и
  «состояние: штатный план / рекомендация: можно по плану». Это не украшение текста:
  карточка — единственный вход, куда смотрит человек перед тренировкой. `return` ведёт себя
  так же (код 0 на пустых данных).
- **D2. Трейсбек вместо сообщения.** `illness`, `refresh`, `refresh --deep`, `ml`, `score`
  на неполной базе выдают необработанное исключение. Пользователь видит не «чего не
  хватает», а стек вызовов; `stdout` при этом пуст — стадийные пометки не печатаются.
- **D3. Скрытая зависимость стадий.** `refresh --journal …` падает на `aw_meta`, потому что
  слепок журнала пишется в таблицу, которую создаёт **другая** стадия (часы). Пропуск
  стадии ломает следующую — это дефект порядка, а не данных.

Отдельно: **README-обещание «шаг не падает» неверно** для базы без `aw_daily`. Оно верно
только когда таблицы часов уже есть — то есть в случае «нет свежего файла», а не «чистый
клон».

## 3. Варианты

### A — терпимый конвейер (tolerant mode)

1. `_open` (или флаг) разрешает старт с пустой схемой.
2. `illness.build` при отсутствии `aw_daily` не бросает, а пишет предупреждение стадии и
   пропускается; так же `ml`.
3. `digest` на пустой базе печатает «нет данных» вместо «штатный план».
4. В таблице свежести стадия помечается `(недостаточно данных)`.

**Цена:** правки в `cli.py`, `refresh.py`, `illness.py`, `digest.py` + ~4 теста.
**Риск:** маскировка. Сейчас единственный признак «данных нет» — падение; после A тот же
код 0 будет означать и «всё хорошо», и «данных нет». Человек, у которого сломался экспорт,
увидит зелёный отчёт. Компенсация — предупреждение в stderr, но в карточку оно не попадёт.

### B — оставить гварды, честный README (readme-first)

1. Гварды не трогаем.
2. В README — раздел «Чистый клон без data/»: какая команда что требует, что печатает,
   какой код возвращает.
3. Поведение фиксируется тестом (тексты и коды), чтобы README не разошёлся с кодом.

**Цена:** минимальная, кода нет — только README + тест на тексты.
**Риск:** низкий (ничего не маскируется).
**Ограничение, которое выяснилось замером:** «честный README» обязан написать, что
`refresh`, `illness`, `ml`, `score` падают **трейсбеком**. Это правда, но это плохой
продукт: README документирует стек вызовов как норму.

### B′ — гварды + читаемая ошибка (без терпимости)

То же, что B, плюс: каждая из пяти трейсбек-точек заменяется на одну строку сообщения и
exit 1 (`illness.build`, `ml`, `score`, стадия `refresh`, `aw_meta` в стадии журнала).
Никакого пропуска стадий, никакой подстановки пустых данных — отказ остаётся отказом, но
читаемым. README описывает фактическое поведение.

**Цена:** точечные гварды + ~5 тестов на тексты (без изменения логики расчётов).
**Риск:** низкий — поведение «не считать» сохраняется, меняется только форма сообщения.
**Отличие от A:** A **продолжает** работу без данных; B′ **отказывается** её продолжать.

### C — точечный фикс двух мест

1. `digest` на пустой базе → отказ (D1).
2. `illness.build` при отсутствии `aw_daily` → сообщение вместо трейсбека (D2, только там).
3. README не трогаем.

**Цена:** ~1 час + 2–3 теста.
**Риск:** средний — `ml`, `score`, `aw_meta` остаются с трейсбеками, README по-прежнему
обещает «не падает». Лечит симптом, а не расхождение.
