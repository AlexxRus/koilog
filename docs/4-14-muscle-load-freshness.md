# 4.14 — Витрина «Нагрузка по мышцам» и «Свежесть мышц»

Статус: черновик спецификации (введена по пожеланию владельца 24.10.2026 —
референс: стороннее приложение-аналог, скриншоты «мышечная нагрузка» / «свежесть мышц»).
Перед кодом — короткий пререг: зафиксировать правило деления и пороги
свежести ДО расчёта (пост-хок лов запрещён — канон 4.4).

Целевые пункты ревизионного списка: E2-вывод (п.16) + E4 (п.18).

## Зависимости

- **4.9** (резолв имён) — все сеты матчатся в словарь.
- **4.10** (справочник мышц в репо) — источник «упражнение → мышцы».

## Вид A — «Нагрузка по мышцам»

- Периоды: тренировка / календарная неделя / произвольный интервал.
- Объём по мышце = Σ по сетам (тоннаж; параллельно — счёт сетов) **÷ N**,
  где N — число мышц записи справочника (равное деление 1/N).
- Проценты распределения (как в сторонних фитнес-приложениях: кольцо + доли групп) — **производная
  витрины на выводе**; в справочник и вход расчёта НЕ возвращаются
  (фенс 4.2/D11-b: доли участия не вводятся).
- Взвешенные доли (веса участия, E2-вход) — только по отдельному пререгу с
  критерием ±20%, если витрина покажет потребность. По умолчанию 1/N.
- Рендер в ноутбуке (matplotlib): горизонтальные бары по мышцам; кольцо —
  опция. Подпись витрины: «display-only».

## Вид B — «Свежесть мышц»

- По каждой мышце: **дни с последнего стимула** (E4) + статус
  «восстановлена / восстанавливается» (зелёный/жёлтый).
- Стимул по мышце = сет, где мышца входит в разметку упражнения (объём —
  по правилу 1/N из вида A).
- Порог «восстановлена» (фиксированное окно по мышце vs адаптивный по
  объёму окна) — пререгистрируется в пререге до первого расчёта.
- MVP: цветная таблица/бары по 17 меткам мышц. Схема тела —
  опция после MVP, не блокирует.

## Исключения из расчёта

- Разминка (метка «—»), кардио, статика (`is_static=1` — обе Планки,
  утверждено 24.10.2026): вне динамической мышечной нагрузки.

## Фенсы (не пересматриваются)

- Display-only: витрина никогда не входит в решения
  (state/gate/ramp/digest.recommend/ml_*), включая ramp.
- Любое аналитическое использование (влияние на рекомендации/гейты) —
  отдельный пререг с критерием ±20%.
- Справочник 4.10 остаётся без процентов (multi-label).

## Критерий готовности

Два вида в ноутбуке на живых данных; правило 1/N и пороги свежести
зафиксированы в пререге до расчёта; тест на деление 1/N (синтетика);
smoke ноутбука.
