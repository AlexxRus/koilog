## 1. Расшифровка меток (дословно, восстановлено)

Так выглядел исходный список (пункты 1–19, секции A–F):

### A. Четыре правки из разбора
1. **Односторонний гейт** (`retrain.baseline_gate`) — убрать `abs()` у ВСР/RHR
   (ВСР < −1, RHR > +1, T уже односторонняя). Перегонка сделана (294 дня
   освобождаются). Осталось: правка кода, тесты (включая «высокая ВСР не
   блокирует»), зафиксировать перегонку.
2. **Рецидивы внутрикластерные vs de novo** — разбить «37 % vs 0 %» по onset'ам
   ≤14 дн от исходного эпизода; правило не меняется.
3. **Nowcast-скор в дайджесте + UX карточки** — брать скор последнего дня из
   walk-forward (не по чистой физиологии), устранить противоречие «все каналы в
   фоне / рекомендация покой» (показ полосы гейта).
4. **Детрейн-кривая** — разбить бакет >28 дн на 28–60 и >60, медиана+размах,
   подпись знака «просадки».

### B. ML и алертинг
5. **State-машина «перерыв → рампа → штатный» (Q1)** — winsorize
   `days_since_training`, подавление алертов в простоях, split FP «в перерыве /
   в тренировочном режиме», отдельно Round 4.
   - **5a. Адаптивный целевой вес в рампе** (переиспользовать
     `koilog.training.*`): если лучший сет до болезни соответствует переходу на
     следующий вес в стеке — целевой = следующий вес стека (округлён до
     доступного), повторы 6; иначе консервативно (лучший вес −1 по стеку). Не
     дублировать логику стека/переходов.
6. **Правило #0 — дайджест-алерт** в `recommend()` (`digest.py`) — логично
   увязать с п. 3.

### C. Свежесть, витрина и текущие проверки
7. **Табличный вид свежести** — `format_freshness` → таблица «таблица | дата»
   (CLI + ячейка 2), пересборка выводов ноутбуков.
8. **README ML-секция устарела** — цифры на 33 эпизода → обновить под 34
   (recall 0.62, уловимых 24/34, nowcast +0.15 [+0.01,+0.29], физиология 0.521).
9. **C9. Пара 33/34 — проверка** (одноразовый print окон меток; в коммит не
   идёт). Результат: окна корректны, двойного счёта нет, nowcastable 30.
10. **C10. Refresh guard (отсутствует файл экспорта)** — `apple.resolve_source`
    бросает `FileNotFoundError` на чистом клоне без архива. В `refresh.run`:
    ловить `FileNotFoundError`, тихо работать от БД (без парсинга), стадия
    «выгрузка (нет файла — работаю от базы)». Покрыть тестом.
11. **C11. README — семантика `--xml`** — одно предложение: `--xml` задаёт
    источник вручную; слепок (`refresh_source`) действует и для него — разбор
    только когда файл изменился. Упомянуть поведение при отсутствии файла.

### D. Следующий раунд (уточнения и кейсы)
12. **D10. Односторонний гейт — ретро-тест на «высокую ВСР перед рецидивом»**.
    Карточка 19.10 (z_ВСР +4.5 накануне рецидива) — аргумент против наивно
    одностороннего гейта. Обязать ретро-тест включать такие случаи, либо
    рассмотреть вариант односторонности + окно тишины N дней после эпизода
    (уточняет A1).
13. **D11. Кейс эп-34 (атрибуция + Round 4)** — первый живой внутрикластерный
    рецидив (через 6 дн после конца 33-го). Посмотреть тоннаж 14–18.10 против
    рампы — готовый кейс для атрибуции и Round 4.
14. **D12. Проспективная валидация (автоматические снапшоты скоров)** — дайджест
    автоматически пишет **дневной снапшот скоров** в таблицу (без ручного
    ввода), тогда 19.10 станет «днём 1».

### E. Мышечные группы (важная ветка)

16. **E2.** Процент участия мышечной группы в упражнении (multi-muscle split:
