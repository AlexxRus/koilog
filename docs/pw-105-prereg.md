## §1 Объём и границы

**Что закрываем:** экспертную role-таблицу долей (`_SHARES_V1`, P=4/S=2/T=1) заменяем версией **v2**, где доля
мышцы в профиле упражнения выводится из литературы по поверхностной ЭМГ (%MVC), а у каждой строки есть
провенанс: № источника, DOI/журнал, дата выписки, уровень доказательности. Слой тот же — **display-only** (PW-99).

**Что НЕ делаем:**
- не пересчитываем канон **E = stored `sets.weight × reps`** (RM-98 / W1 = A) — меняется только
  **распределение** уже посчитанной нагрузки по мышцам;
- не пишем в базу (все замеры `mode=ro`);
- не трогаем `state`/`retrain`/`digest`/`score`/`ml`/`groups` — фенсы D11-b и display-only в силе;
  `muscle_load.py` (кольцо `1/N`, свежесть) не трогаем — другая семантика;
- не заявляем «долю силы» (sEMG-амплитуда — **относительная активация**, не механический вклад), точность
  ±5 п.п. и сравнение мышц между разными исследованиями — тоже (§7).

**Зачем v2:** v1 — экспертная догадка без источника, даты и уровня. Из 58 пар «профиль × мышца» числа сейчас
извлекаются только для **22** (§3.5). Вывод не «подождать», а «сделать провенанс явным»: v2 показывает, где число
из статьи, где ждёт PDF, где остаётся экспертной оценкой, а где мышца вообще не измеряется поверхностной ЭМГ.

## §5 Инварианты и фенсы

1. **Σ=1:** для каждого профиля и каждого override `Σ share_i = 1` (v1 и v2).
2. **Сохранение E:** для каждого подхода `Σ_i share_i × E = E`; `check_invariant` → `residual = 0.000000`; `Σ_m kg_m = E_total` (§2.4).
3. **Канон E не тронут:** `weight`/`rm`/`koi`/`load_daily` не пересчитываются; PW-105 не пишет в базу.
4. **Display-only (оба направления):** `state`/`retrain`/`digest`/`score`/`ml`/`groups` не импортируют `muscle_share`; `muscle_share` не импортирует их (разрешены `muscles`, `taxonomy`, `equipment`).
5. **v1 воспроизводим:** `_SHARES_V1` не меняется; переключение на v1 даёт числа §2 бит-в-бит.
6. **Провенанс полон:** у каждой строки v2 есть `source_ids`, `extracted_at`, `level`, `numbers`; пустых полей нет; DOI либо есть, либо заменён строкой журнала (не пусто).

## §7 Честные пределы

- **sEMG ≠ силовой вклад.** Амплитуда зависит от кросс-тока, отмены, глубины мышцы и расположения электродов
  (Vigotsky 2017, №4; Felici & Del Vecchio 2020, №5; SENIAM, №6). «Доля силы» — запрещённая формулировка (Р4).
- **%MVC зависит от протокола:** %1RM, фаза (концентрика/эксцентрика), скорость, угол в суставе. Смешивать
  протоколы разной нагрузки нельзя; «взвешенное среднее по n» — компромисс, не физическая величина.
  **±5 п.п. не заявляем**, сравнение мышц — только **внутри одного исследования**.
- **Неполнота реальна:** 26 пар — C, 5 — «не измерено», 25 — без источника вообще; v2 — гибрид.
  **Внутрипрофильная вариация потеряна:** один профиль покрывает 1–14 упражнений (жим лёжа vs с наклоном
  не различаются). **Антагонисты и стабилизаторы не представлены** (кроме №27 и то частично).
- **Абстрактные строки временные:** после PDF числа могут измениться; до этого v2 держит v1 с пометкой.
  **Никаких выводов о гипертрофии/силе/травмах** из долей не следует: это учёт нагрузки, не прогноз.
